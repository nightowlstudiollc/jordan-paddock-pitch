# Jordan Paddock & Them Boys — pitch site

A responsive, buildless website concept by Night Owl Studio. Static HTML/CSS/JavaScript, with local photos and fonts. No dependency installation or build needed.

## Preview

Run `python3 -m http.server 8080 --directory dist`, then open http://localhost:8080.

## Netlify

Connect this repository to a new Netlify project. `netlify.toml` sets the publish directory to `dist`; leave the build command empty. Use a Deploy Preview or manual draft deploy to share the concept, without a custom domain. `.netlify/` is ignored so local linking state stays out of Git.

## Content status

- Photos and logo reused from https://www.jordanpaddockofficial.com/ with Andrew's authorization for this pitch. Retain the band's permission and any photographer attribution before an official launch.
- EP track names and streaming artist links come from Apple Music and Spotify. The logo-on-record treatment is concept artwork, not the actual release sleeve.
- About text is placeholder copy. All show listings explicitly say they are illustrative; no dates or ticket sales are claimed.
- Video tiles open an accessible placement-preview dialog, not a real music video.
- Booking opens Jordan's published email address; there is no form or data collection.
- Search indexing is disabled for the pitch.
- Fonts: Google Fonts Barlow Condensed and DM Sans, distributed under the SIL Open Font License. See `FONT-LICENSES.md`.

## Before official launch

Confirm band copy, show dates, purchase link and preferred storefront/region, live footage, image rights/credits, domain ownership, and update workflow. Remove noindex only when Jordan approves a public launch.
